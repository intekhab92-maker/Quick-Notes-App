📝 Quick Notes App

A clean, responsive, and lightweight Note-Taking web application built with React and LocalStorage for persistent client-side data management.

---
✨ Features

 Instant Note Creation: Add notes with a title and description.
 Real-Time Search: Filter notes dynamically by title or keywords.
 LocalStorage Persistence: Notes remain saved even after page refresh or browser close.
 Delete Functionality: Remove notes instantly with a single click.
 Responsive Grid: Mobile and desktop friendly UI.


🛠️ Tech Stack

Frontend: React.js (Hooks: `useState`, `useEffect`)
Storage: Browser `localStorage` API
Styling: Modular CSS
